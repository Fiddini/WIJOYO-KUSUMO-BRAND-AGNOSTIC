# WIJOYO-KUSUMO-BRAND-AGNOSTIC
WIJOYO-KUSUMO — Brand-Agnostic Medical Device Integration. An OTRIS engineering workbench dedicated to connecting medical devices across manufacturers through open, verifiable, and interoperable technology.

## What this is

This is an engineering workbench for building brand-agnostic integration.

The goal is simple: different brands, one clean way to connect, verify, and log data.

Focus areas:
- Clean device integration
- Verifiable data flow
- Interoperable design across manufacturers
- Safe engineering practice

## What this is not

This repository does not contain production medical code, or patient data.

No device is claimed to be supported until it is tested and verified here.
